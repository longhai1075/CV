## Giới thiệu dự án

Dự án **KT A2.1** là trang Portfolio cá nhân của **Nguyễn Long Hải** (Sinh viên lớp **CNTT 17-09**), được thiết kế để giới thiệu bản thân, trình bày các kỹ năng, sản phẩm dự án đã hoàn thành và phương thức liên hệ tuyển dụng / hợp tác.

### Điểm nổi bật
- **Giao diện hiện đại & thanh lịch**: Phối màu hài hòa, bố cục trực quan với trải nghiệm đọc tốt.
- **Responsive Design**: Tương thích hoàn hảo với màn hình Mobile, Tablet và Desktop (sử dụng Flexbox và CSS Grid).
- **Hiệu năng cao**: Thuần HTML5 & CSS3 không phụ thuộc thư viện nặng, tốc độ tải trang tức thì.
- **Semantic HTML & Trợ năng (A11y)**: Đầy đủ cấu trúc thẻ ngữ nghĩa (`<header>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`) cùng thuộc tính `aria-label`, thẻ meta SEO.
- **Điều hướng mượt mà**: Menu anchor linh hoạt giúp di chuyển nhanh giữa các phần trang.

## Công nghệ sử dụng

- **HTML5**: Cấu trúc ngữ nghĩa chuẩn SEO và hỗ trợ công cụ đọc màn hình.
- **CSS3**:
  - **CSS Variables**: Quản lý màu sắc, typography và khoảng cách dễ bảo trì.
  - **Flexbox & CSS Grid**: Tạo layout linh hoạt, co giãn theo kích thước màn hình.
  - **Transitions & Hover Effects**: Tương tác mượt mà với người dùng.

## Hướng dẫn chạy thử dự án

Dự án là trang tĩnh (Static Web Page), không cần cài đặt môi trường phức tạp:

### Cách 1: Mở trực tiếp
Nhấp đúp chuột vào file `index.html` hoặc mở bằng trình duyệt bất kỳ (Chrome, Edge, Safari, Firefox).

### Cách 2: Sử dụng VS Code Live Server
1. Cài đặt extension **Live Server** trong Visual Studio Code.
2. Chuột phải vào file [index.html](file:///Users/chun/Downloads/KT%20A2.1/index.html) và chọn **"Open with Live Server"**.
3. Trang sẽ được phục vụ tại địa chỉ `http://127.0.0.1:5500`.
